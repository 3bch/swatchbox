# デザインシステム

見本は [prototype/design-system.html](../prototype/design-system.html) にある。

- CSS 変数の名前は shadcn/ui に揃える
- ダークモードは作らない（[styling.md](styling.md)）
- iPhone は対象にしないので、safe-area には対応しない

## 色

oklch で書く。

| 変数                     | 値                          | 使うところ                       |
| ------------------------ | --------------------------- | -------------------------------- |
| `--background`           | `oklch(0.979 0.008 357.8)`  | 画面の背景                       |
| `--stage`                | `oklch(0.961 0.0013 286.4)` | 箱の絵の背景（shadcn/ui にない） |
| `--foreground`           | `oklch(0.235 0.016 349.9)`  | 本文                             |
| `--card`                 | `oklch(1 0 0)`              | 選択中のタブ                     |
| `--card-foreground`      | `oklch(0.235 0.016 349.9)`  |                                  |
| `--popover`              | `oklch(1 0 0)`              | ダイアログ                       |

| `--primary-foreground`   | `oklch(1 0 0)`              |                                  |
| `--secondary`            | `oklch(0.938 0.03 342.6)`   | 控えめなボタン、新しい布         |
| `--secondary-foreground` | `oklch(0.402 0.15 352.4)`   | 入力欄の枠                       |
| `--muted`                | `oklch(0.956 0.013 353.1)`  | タブの外枠                       |

| `--accent`               | `oklch(0.938 0.03 342.6)`   |                                  |

| `--destructive`          | `var(--primary)`            | 削除                             |

| `--ring`                 | `oklch(0.51 0.197 353.9)`   | フォーカス、選択中の布の枠       |

### 削除の色をメインの色と同じにする

- 削除の色は、検討したうえで `--primary` と同じにした
- 削除のボタンは、ゴミ箱のアイコンと文言で見分ける

### 削除のボタンは置かれる場所で塗りを変える

| 場所                             | 見た目                              |
| -------------------------------- | ----------------------------------- |
| 確認ダイアログの「削除」         | `--destructive` の塗りに白い文字    |
| 編集ダイアログの「この布を削除」 | 10% の塗りに `--destructive` の文字 |

- 確認ダイアログでは、隣のキャンセルと一目で見分けたいので塗る
- 編集ダイアログでは単独で置かれるため、薄い塗りでも取り違えない

### コントラスト比

文字は 4.5 以上、枠線は 3 以上を目安にする。

| 組み合わせ                           | 比                 |
| ------------------------------------ | ------------------ |
| 本文                                 | 15.73              |
| 補足（背景 / 薄い塗り / ダイアログ） | 5.44 / 5.07 / 5.79 |
| ボタン                               | 6.43               |
| 控えめなボタン                       | 8.18               |
| 削除の文字、選択の枠                 | 6.04               |
| 選択の枠（箱の背景の上）             | 5.74               |
| 入力欄の枠（背景 / ダイアログ）      | 9.32 / 9.93        |

### 入力欄は塗りと枠の両方で示す

入力欄は布編集ダイアログの「名前」だけで、まわりは白い面になる。
面より少し沈んだ塗りに、同じ系統の濃い枠を重ねて、書く場所だと示す。

- 塗りは `--secondary` の 55%、枠は `--secondary-foreground` にする
- 枠と塗りが同じ系統なので、ひとつの部品としてまとまって見える
- フォーカスすると枠が `--ring` に変わり、3px の輪が付く

## 文字

Zen Maru Gothic を使う。

| 段階 | 大きさ | 太さ | 行の高さ | 使うところ                     |
| ---- | ------ | ---- | -------- | ------------------------------ |
| lg   | 18px   | 700  | 1.4      | シートの見出し                 |
| base | 16px   | 500  | 1        | ダイアログの見出し             |
| base | 16px   | 500  | 1.5      | ボタン、布の名前               |
| base | 16px   | 400  | 1.5      | 本文、入力欄                   |
| sm   | 14px   | 500  | 1.5      | タブ、入力欄のラベル           |
| sm   | 14px   | 400  | 1.5      | 補足、一覧の布の名前           |
| xs   | 12px   | 400  | 1.5      | 画面の見本ではまだ使っていない |

- 太さは 400 / 500 / 700 の 3 つだけ読み込む
- 入力欄は、ブラウザの自動拡大を避けるため 16px にする

### フォントの配信

`@fontsource` でアプリに同梱する。

- オンラインで使うのが前提だが、通信が弱くても表示できるようにしたい
- Google Fonts は別ドメインなので、Service Worker でキャッシュしにくい
- 同梱すれば、アプリ本体と同じようにキャッシュできる
- 日本語は文字の範囲ごとに分かれていて、使う範囲だけ読み込まれる

## 角丸

`--radius` を 10px にし、ほかの段階はそこから計算する。

段階の倍率は Maia のものをそのまま使う。

| 段階 | 倍率 | 値    | 使うところ                                            |
| ---- | ---- | ----- | ----------------------------------------------------- |
| sm   | 0.6  | 6px   | 小さな布の画像                                        |
| md   | 0.8  | 8px   | 布の画像                                              |
| lg   | 1    | 10px  | 今は使わない                                          |
| xl   | 1.4  | 14px  | 箱の絵の下にある一覧の上の角                          |
| 2xl  | 1.8  | 18px  | 今は使わない                                          |
| 3xl  | 2.2  | 22px  | 今は使わない                                          |
| 4xl  | 2.6  | 26px  | ダイアログ                                            |
| full | —    | 999px | ボタン、入力欄、タブの外枠とボタン、チェック、…ボタン |

### タブはピル形にする

Maia の角丸は高さ 36px を前提にした値で、その高さではピル形になる。
高さを 48px にしたので、そのまま使うと外枠と中のタブの角が噛み合わない。
外枠も中のタブもピル形にすると、48px と 42px が同じ中心で重なる。

## 余白

Tailwind の 4px 刻みだけを使う。

| 段階 | 値   | 使うところ                                                       |
| ---- | ---- | ---------------------------------------------------------------- |
| 1    | 4px  | タブのボタンどうしの間                                           |
| 2    | 8px  | アイコンと文字、並んだボタン、ラベルと入力欄、布の画像と名前の間 |
| 3    | 12px | 布の一覧の横の間、入力欄の内側                                   |
| 4    | 16px | 画面の左右、布の一覧の縦の間                                     |
| 5    | 20px | ボタンの左右の内側                                               |
| 6    | 24px | ダイアログの内側、ダイアログの中の要素どうしの間                 |
| 8    | 32px | 箱の絵の下                                                       |

- タブの外枠の内側は、Maia に揃えて 3px にする（4px 刻みの例外）
- ダイアログの中の要素どうしの間は、Maia に揃えて 24px にする

## 高さ

余白とは分けて、3 段階にする。

| 値   | 使うところ                                      |
| ---- | ----------------------------------------------- |
| 48px | ボタン、入力欄、蓋・外側・内側のタブ            |
| 42px | 表示状態のタブ（外枠の内側を含めて 48px）       |
| 32px | 布の…ボタン（タップできる範囲は 44px に広げる） |

## 影と暗幕

Maia の値に揃える。

- ダイアログ：影を落とさず、`--foreground` の 5% で 1px の輪郭を描く
- 暗幕：黒の 80% に、4px のぼかしを重ねる

## フォーカスと押したとき

Maia の値に揃える。

- フォーカス：枠を `--ring` の色にし、`--ring` の 50% の色で 3px の輪を付ける
- 押したとき：ボタンを 1px 下に動かす

## Maia に揃えたもの、揃えなかったもの

見本の切り替えで見比べて決めた。比べ終えたので、切り替えは見本から消した。

### 揃えたもの

| 項目                   | 値                                       |
| ---------------------- | ---------------------------------------- |
| 角丸                   | 段階の倍率。ダイアログは 4xl（26px）     |
| ダイアログの見出し     | 16px、太さ 500、行の高さ 1               |
| ダイアログの影         | 影をやめ、1px の輪郭にする               |
| 暗幕                   | 黒 80% にぼかし 4px                      |
| 編集ダイアログの削除   | 10% の塗りに色の文字                     |
| outline ボタン         | 枠は `--border`、塗りは `--input` の 30% |
| フォーカス、押したとき | 上の「フォーカスと押したとき」のとおり   |
| ダイアログの要素の間   | 24px                                     |
| タブの外枠の内側       | 3px                                      |

### 揃えなかったもの

| 項目                 | Maia の値            | この文書の値                                               | 理由                                         |
| -------------------- | -------------------- | ---------------------------------------------------------- | -------------------------------------------- |
| 高さ                 | 36px                 | 48px                                                       | スマホで押すには小さい                       |
| ボタンの文字と余白   | 14px、左右 12px      | 16px、左右 20px                                            | 高さ 48px に 14px は間延びして見える         |
| 確認ダイアログの削除 | 10% の塗り           | `--destructive` の塗り                                     | 隣のキャンセルと見分けが付かない             |
| 入力欄の塗りと枠     | `--input` の薄い塗り | 塗りは `--secondary` の 55%、枠は `--secondary-foreground` | 塗る考え方は倣い、隣のボタンと色で分ける     |
| 選択中のタブ         | 背景色、影なし       | 白に影                                                     | 外枠との差が小さく、選んだタブが分かりにくい |

## アプリにするときに扱うこと

### トークンにする

見本では直接書いている、次の値もトークンにする。

- 箱の絵の色（布が未選択のときの色、輪郭線、陰影の濃さ）
- 暗幕の濃さとぼかし

### shadcn/ui の導入

- Maia で init し、揃えられる値は Maia に揃える（[styling.md](styling.md)）
    - 色とフォントは、この文書の値を残す
    - どの値を揃えたかは「Maia に揃えたもの、揃えなかったもの」に書いた
- Maia に揃えない部品の高さは、生成物を common の自前の部品で包んで上書きする
    - 生成されたコードには手を入れないため
- `--chart-*` と `--sidebar-*` は使わないので消す
    - Chart（グラフ）と Sidebar（横に出るナビゲーション）の部品が使う変数
