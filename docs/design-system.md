# デザインシステム

見本は [prototype/design-system.html](../prototype/design-system.html) にある。

- CSS 変数の名前は shadcn/ui に揃える
- ダークモードは作らない（[styling.md](styling.md)）
- iPhone は対象にしないので、safe-area には対応しない

### 削除の色をメインの色と同じにする

- 削除の色は、検討したうえで `--primary` と同じにした
- 削除のボタンは、ゴミ箱のアイコンと文言で見分ける

### コントラスト比

文字は 4.5 以上、枠線は 3 以上を目安にする。

| 組み合わせ                           | 比                 |
| ------------------------------------ | ------------------ |
| 本文                                 | 15.73              |
| 補足（背景 / 薄い塗り / ダイアログ） | 5.44 / 5.07 / 5.79 |
| ボタン                               | 6.43               |
| 控えめなボタン                       | 8.18               |
| 削除の文字、選択の枠                 | 6.04               |
| 選択の枠（箱の背景の上）             | 5.74               |
| 入力欄の枠（背景 / ダイアログ）      | 2.05 / 2.18        |

### 入力欄の枠は目安から外す

`--input` は 2.05 で、枠線の目安（3 以上）を満たさない。
1.4、2、3 の 3 案を並べて比べ、2 にした。

- 1.4 だと、ダイアログの上のキャンセルボタンが押せる部品に見えにくい
- 3 だと、灰色がかった枠が目立ち、やわらかい雰囲気に合わない
- 入力欄は布編集ダイアログの「名前」だけで、ラベルがあるので入力欄だと分かる
- outline ボタンは、いつも primary ボタンと並んでいる

## 文字

Zen Maru Gothic を使う。

| 段階 | 大きさ | 太さ | 行の高さ | 使うところ                     |
| ---- | ------ | ---- | -------- | ------------------------------ |
| lg   | 18px   | 700  | 1.4      | シートとダイアログの見出し     |
| base | 16px   | 500  | 1.5      | ボタン、布の名前               |
| base | 16px   | 400  | 1.5      | 本文、入力欄                   |
| sm   | 14px   | 500  | 1.5      | タブ、入力欄のラベル           |
| sm   | 14px   | 400  | 1.5      | 補足、一覧の布の名前           |
| xs   | 12px   | 400  | 1.5      | 画面の見本ではまだ使っていない |

- 太さは 400 / 500 / 700 の 3 つだけ読み込む
- 入力欄は、ブラウザの自動拡大を避けるため 16px にする

### フォントの配信

`@fontsource` でアプリに同梱する。

- オンラインで使うのが前提だが、通信が弱くても表示できるようにしたい
- Google Fonts は別ドメインなので、Service Worker でキャッシュしにくい
- 同梱すれば、アプリ本体と同じようにキャッシュできる
- 日本語は文字の範囲ごとに分かれていて、使う範囲だけ読み込まれる

## 角丸

`--radius` を 10px にし、ほかの段階はそこから計算する。

| 段階 | 値    | 使うところ                             |
| ---- | ----- | -------------------------------------- |
| sm   | 6px   | 小さな布の画像                         |
| md   | 8px   | ボタン、入力欄、タブのボタン、布の画像 |
| lg   | 10px  | ダイアログ、タブの外枠                 |
| xl   | 14px  | 箱の絵の下にある一覧の上の角           |
| full | 999px | チェック、…ボタン                      |

## 余白

Tailwind の 4px 刻みだけを使う。

| 段階 | 値   | 使うところ                                                       |
| ---- | ---- | ---------------------------------------------------------------- |
| 1    | 4px  | タブの外枠の内側、タブのボタンどうしの間                         |
| 2    | 8px  | アイコンと文字、並んだボタン、ラベルと入力欄、布の画像と名前の間 |
| 3    | 12px | 布の一覧の横の間、入力欄の内側                                   |
| 4    | 16px | 画面の左右、布の一覧の縦の間、ダイアログの中の要素どうしの間     |
| 5    | 20px | ボタンの左右の内側                                               |
| 6    | 24px | ダイアログの内側                                                 |
| 8    | 32px | 箱の絵の下                                                       |

## 高さ

余白とは分けて、3 段階にする。

| 値   | 使うところ                                      |
| ---- | ----------------------------------------------- |
| 48px | ボタン、入力欄、蓋・外側・内側のタブ            |
| 40px | 表示状態のタブ（外枠の内側を含めて 48px）       |
| 32px | 布の…ボタン（タップできる範囲は 44px に広げる） |

## アプリにするときに扱うこと

### トークンにする

見本では直接書いている、次の値もトークンにする。

- 箱の絵の色（布が未選択のときの色、輪郭線、陰影の濃さ）
- 影、暗幕の濃さ

### shadcn/ui の導入

- 部品の高さは、生成物を common の自前の部品で包んで上書きする
    - 生成されたコードには手を入れないため
- `--chart-*` と `--sidebar-*` は使わないので消す
    - Chart（グラフ）と Sidebar（横に出るナビゲーション）の部品が使う変数
- init の方式（CLI でベースカラーを選ぶか、create のプリセットか）は、導入するときに決める
    - どちらでも、生成された CSS 変数をこの文書の値に置き換える
    - CLI の選択肢は変わりやすいので、そのときの最新の情報を確かめる
