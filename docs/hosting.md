# 保存先と公開先

## 布の保存先

布は IndexedDB に保存する。

- データはスマホの中だけに置く
- Android の Chrome でホーム画面に追加して使えば、ブラウザが勝手に消すことはまずない

### Supabase にしなかった理由

| 理由                           | 内容                                                             |
| ------------------------------ | ---------------------------------------------------------------- |
| 無料プランの一時停止           | 1 週間アクセスがないと停止し、久しぶりに開くと使えないことがある |
| ログインまわりを作る必要がある | 1 人・1 台で使う MVP には手間が大きい                            |
| 店内での遅さ                   | 電波が弱いと、画像のアップロードや読み込みが遅くなる             |

## アクセス

身内に限る仕組みは設けない。

- データは端末内にあり、URL を知られても空のアプリしか見えない
- あとから限りたくなったら、Cloudflare Access を足す

## デプロイ先

Cloudflare にデプロイする。

- PR ごとにお試し URL ができ、スマホの実機で確かめやすい
- URL がサイト直下になり、Vite やルーターにパスの設定が要らない
- あとから Cloudflare Access を足せる
- Workers と Pages のどちらを使うかは、デプロイを設定するときに決める

## 機種変更したとき

MVP では、新しいスマホで布を登録し直す。

- 手持ちの布は手元にあるので、撮り直せる
- 布の保存と読み込みの処理は 1 か所にまとめ、あとで保存先を変えやすくしておく
- バックアップの書き出しと読み込みは、あとで考える
