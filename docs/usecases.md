# ユースケース

## 使う人

- 箱を作る人（身内）1 人
- スマホ 1 台で使う

## 使う場面

| 場面                   | やりたいこと                                             |
| ---------------------- | -------------------------------------------------------- |
| 手持ちの布から選ぶとき | 登録済みの布を組み合わせて、完成イメージを確かめる       |
| 布を買う前・買うとき   | 店頭で布を撮って登録し、手持ちの布と組み合わせて確かめる |
| 人に見せるとき         | 完成イメージをスマホの画面でそのまま見せる               |

## ユースケース

### 布を登録する

- カメラで撮影するか、撮影済みの写真を選ぶ
- 写真から、布として使う範囲を切り抜く
- 名前を付ける
- 手持ちの布と買う前の布は区別せず、同じ一覧に登録する

### 布を管理する

- 登録した布を、画像と名前の一覧で見る
- 名前を変える
- 要らなくなった布を削除する

### 布を割り当てる

- 蓋・外側・内側の 3 か所それぞれに、一覧から布を選ぶ

### 完成イメージを確かめる

- 「蓋を閉めた状態」「蓋を外した状態」「手前を透かした状態」を切り替えて見る
- 柄の大きさはアプリが決める

## MVP に含めないもの

| もの                               | 理由                                             |
| ---------------------------------- | ------------------------------------------------ |
| 組み合わせの保存と呼び出し         | あるとうれしいが、スクリーンショットで代用できる |
| カラーコードで指定する単色の布     | あるとうれしいが、最初はなくてよい               |
| 柄の大きさの調整（実寸・拡大縮小） | 必要な精度がわからず、作りながら判断する         |
| 完成イメージの画像書き出し・共有   | 画面をそのまま見せれば足りる                     |
| 複数端末でのデータ共有             | スマホ 1 台で使う                                |
